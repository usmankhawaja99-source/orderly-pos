The 4-Minute Floor Playbook

1. Floor Navigation

1 Tap on any table tile previews the live check. 2 Taps opens the order editor immediately.

2. Under 3-Click Ordering

Tap a menu item on the left to add it to the check—its specific modifications pop up right above the totals on the same screen.

3. Ticket Muscle Memory
